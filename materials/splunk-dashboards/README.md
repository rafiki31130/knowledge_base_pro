# Dashboards Splunk

Dashboards génériques, à coller en source d'un nouveau dashboard (`Edit > Source`). Chaque
dashboard = un fichier source + une fiche `.md` du même nom.

## Dashboards

- [Mes droits](./mes-droits.md) ([source](./mes-droits.xml)) : SimpleXML. Droits effectifs
  de l'utilisateur connecté : rôles, index cherchables, apps (lecture / écriture), capacités.
