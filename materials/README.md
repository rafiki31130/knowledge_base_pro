# Materials

Objets prêts à importer : dashboards, et plus tard d'autres livrables du même genre. Contenu
anonymisé et générique, comme le reste du dépôt : pas d'hôte, d'index ni de rôle propre à une
infrastructure réelle.

Un sous-dossier par famille d'objets, **un seul niveau** : les fichiers vivent directement
dedans, chacun accompagné d'une fiche `.md` du même nom (rôle, pré-requis, sources, limites).
